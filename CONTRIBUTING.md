# Contributing

Please open an issue with a minimal Markdown example, expected behavior, actual
output, operating system, and Python version. Remove private paths and sensitive
content before posting.

For a pull request, include a regression test when changing checking behavior.
Run the unittest suite and the documentation checker as shown in the README.
Keep the default checker offline and avoid adding runtime dependencies without
discussing the tradeoff first.

Changes to unsupported syntax should update both README files. Please be
respectful when reporting issues and reviewing contributions.
